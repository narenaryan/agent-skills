# marketing skills

Evidence-led positioning, causal campaign measurement, cohort-aware funnel diagnosis, and spillover-aware geo testing.

## Skills

- **[marketing-positioning-tests](marketing-positioning-tests/SKILL.md)** - separate positioning assumptions from copy preferences and test messages against customer alternatives and observable behavior.
- **[marketing-incrementality](marketing-incrementality/SKILL.md)** - distinguish attribution from causal lift and design credible campaign holdouts, diagnose downstream sample-ratio mismatch, and preserve uncertainty in decisions.
- **[marketing-geo-experiments](marketing-geo-experiments/SKILL.md)** - plan randomized geo tests, distinguish synthetic-control analyses, and stop when power or isolation cannot support the decision.
- **[marketing-funnel-diagnosis](marketing-funnel-diagnosis/SKILL.md)** - identify measurement errors, cohort shifts, canonical-signal defects, and stage bottlenecks before changing campaigns or conversion flows.

## Install

./install.sh marketing                       # install all

./install.sh marketing-incrementality        # install one
./install.sh marketing-geo-experiments         # install one
./install.sh marketing-funnel-diagnosis       # install one
