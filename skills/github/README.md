# github skills

GitHub-focused operational skills for secure authentication and repository workflows.

## Skills

- **[github-ssh-keys](github-ssh-keys/SKILL.md)** - setting up, troubleshooting, or hardening SSH keys for GitHub across macOS, Windows, and hardware-key workflows.
- **[npm-publish-ci-pitfalls](npm-publish-ci-pitfalls/SKILL.md)** - npm CI publishing edge cases around authentication, package contents, provenance, and registry propagation.

## Install

```bash
./install.sh github               # install all
./install.sh github-ssh-keys      # install one
```
